# Elementary Programming

This folder contains introductory Java programs covering basic input/output, arithmetic operations, and variable handling. Programs range from simple integer addition to payroll calculators that take in employee names, hourly rates, and hours worked. These exercises focus on Scanner usage, formatted output, and working with different data types like int and double.

These programs were completed during guided classroom instruction while following the professor's live demonstrations and practicing foundational Java concepts with the class. They represent early-stage work building familiarity with the Java development environment and core syntax.
