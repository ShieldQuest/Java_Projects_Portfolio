# Temperature Alert System (Java)

This program was created for a homework assignment.

It asks the user for a city name and the current outdoor temperature in °F.  
Based on the temperature, it displays a:

- GREEN (safe)
- YELLOW (caution)
- RED (danger)

The program uses conditionals, a while loop to repeat the program, 
and basic input validation for the repeat option.

Main focus: user input, if/else logic, loops, and clean output formatting.
