# Sorting, Searching, Comparable, and Generic Classes

Programs here cover sorting and searching with the Comparable interface and generic classes. The payroll programs implement custom compareTo() methods to sort employees by SSN using both arrays and ArrayLists. Generic sorting routines demonstrate how a single method can handle Integer, Double, String, and Character types through Java generics.

These exercises were completed during class sessions, following the professor's explanations on how Java's Comparable interface and generics enable flexible, reusable sorting logic.
