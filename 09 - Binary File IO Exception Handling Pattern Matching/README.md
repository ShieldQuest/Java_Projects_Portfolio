# Binary File I/O, Exception Handling, and Pattern Matching

This folder contains a payroll program that demonstrates serializing Employee objects to disk and reading them back using Java's file I/O streams. It also incorporates exception handling for robust error management and pattern matching techniques for SSN validation. The program ties together several advanced topics in a single working application.

This code was written during a class session following the professor's live demonstration on persistence, error handling, and input validation patterns.
