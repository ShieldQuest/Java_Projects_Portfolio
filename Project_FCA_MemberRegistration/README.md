# FCA Member Registration

Java program for a class project. It handles member registration for the Flying Club of America (FCA), which is a made-up non-profit for pilots.

## What it does
- Collects member info (name, phone, email, city/state, etc.)
- Sorts members into Professional Pilot or Amateur Pilot categories
- Displays member details back using dialog boxes (JOptionPane)

## Structure
- `Membership` — base class with general member data and input/display methods
- `Professional` — subclass for professional pilots, adds airline, license number, flight hours, etc.
- `project_Alvarez.java` — main driver class
- `Project_XC_Alvarez.java` — extended/extra credit version

## Notes
- Built with Java , no external libraries
- Uses Swing (JOptionPane) for simple GUI input/output
