# Loops, Methods, and String Type

This folder focuses on method decomposition and string handling in Java. The Addition programs evolve from a single-method approach to fully modularized code with separate methods for input, calculation, and display. The FinancialAid series tackles eligibility logic using income, family size, and veteran status, while also addressing common pitfalls with Scanner and mixed input types.

All programs here were completed during in-class coding sessions, following the professor's demonstrations on refactoring code into methods and handling string input properly.
