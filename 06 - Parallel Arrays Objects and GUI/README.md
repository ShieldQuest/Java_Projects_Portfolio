# Parallel Arrays, Objects, and GUI

This folder covers the transition from parallel arrays to object-oriented design, plus an introduction to GUI programming. Programs include a menu-driven payroll system using parallel arrays, an upgraded version using Employee objects, and a simple addition calculator built with JOptionPane dialogs. String comparison techniques using .equals() versus == are also demonstrated.

These programs were written during class sessions while following the professor's explanations on object-oriented concepts and graphical user interfaces in Java.
