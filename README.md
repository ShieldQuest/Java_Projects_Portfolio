# Java Projects Portfolio

A collection of Java programs developed during coursework at Florida State College at Jacksonville. This repository covers core programming concepts from elementary I/O through advanced topics like inheritance, generics, file I/O, recursion, and JavaFX GUI development.

## Repository Structure

| Folder | Topics |
|--------|--------|
| `01 - Elementary Programming` | Variables, Scanner input, arithmetic operations |
| `02 - Selection and Loops` | If-else logic, while loops, input validation |
| `03 - Loops Methods and String Type` | Method decomposition, String handling, Scanner pitfalls |
| `04 - Methods and Randomness` | Static methods, parameter passing, Math.random() |
| `05 - Intro to Arrays` | Array declaration, traversal, filtering, parallel arrays |
| `06 - Parallel Arrays Objects and GUI` | OOP basics, JOptionPane, String comparison |
| `07 - Array List String Manip Inheritance` | ArrayList, character validation, early inheritance |
| `08 - More Inheritance` | Class hierarchies, polymorphism, method overriding |
| `09 - Binary File IO Exception Handling Pattern Matching` | Serialization, try-catch, regex validation |
| `10 - Sorting Searching Comparable and Generic Classes` | Comparable interface, generics, sorting algorithms |
| `11 - Recursion` | Iterative vs. recursive approaches, factorial |
| `12 - Advanced GUI JavaFX Recursion` | JavaFX interfaces, recursive summation and factorial |
| `Homework Solutions` | Professor-provided reference implementations |
| `Homework Submissions` | Independently written homework assignments |

## About

Folders 01–12 contain programs written during guided classroom sessions while following the professor's live demonstrations. The Homework Submissions folder contains independently developed assignments representing original work.
