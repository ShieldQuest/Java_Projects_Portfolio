# ArrayList, String Manipulation, and Inheritance

Programs in this folder explore ArrayList for dynamic data storage, string validation techniques, and early inheritance concepts. The payroll system evolves to use ArrayList and JOptionPane GUIs. SSN validation programs demonstrate character-level checking with boolean logic. String manipulation exercises show proper character access using charAt() and Character class methods.

All code was completed during in-class coding sessions, practicing alongside the professor's live demonstrations on collections, validation patterns, and string processing.
