# Intro to Arrays

Programs here introduce array fundamentals in Java, progressing from basic declaration and initialization through user input, random population, and passing arrays to methods. The series covers forward and reverse traversal, filtering for even and odd numbers, and refactoring from while loops to for loops. Payroll programs demonstrate parallel arrays for managing multiple employees.

All exercises in this folder were completed during guided classroom sessions, following the professor's demonstrations on how arrays store and process collections of data.
