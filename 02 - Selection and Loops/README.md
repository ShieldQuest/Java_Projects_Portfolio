# Selection and Loops

Programs in this folder explore conditional logic and loop structures in Java. The division program is iterated across seven versions, progressively adding input validation, retry logic with while loops, attempt limits, and repeated operations. Each version builds on the last to demonstrate how real programs handle edge cases like division by zero.

These exercises were written during class sessions while following the professor's step-by-step walkthroughs. The iterative approach helped reinforce how selection statements and loops work together to build robust user-facing programs.
