# More Inheritance

This folder contains a payroll system built around Java inheritance. The program implements a base Employee class with specialized subclasses for Part-Time, Full-Time, and Contractor employees, each with unique attributes and pay calculations. It demonstrates polymorphism, method overriding, and how inheritance reduces code duplication across related types.

This program was developed during classroom instruction, following the professor's walkthrough on designing class hierarchies and applying inheritance in a practical payroll context.
